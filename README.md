# Control de Provisiones · Maipú Zona 6

> Ecosistema interactivo 2025–2030 para el seguimiento contractual de provisiones destinadas a la mantención de áreas verdes.

## 🌿 Acceso directo

### [ABRIR EL DASHBOARD DE PROVISIONES](https://nburgosfigueroa-bit.github.io/PROVISIONES-MAIPU-ZONA-6/)

[Ver repositorio en GitHub](https://github.com/nburgosfigueroa-bit/PROVISIONES-MAIPU-ZONA-6)

## 1. ¿Qué hace este proyecto?

Permite comparar lo exigido por las bases técnicas con las solicitudes y entregas registradas durante cada periodo contractual. Centraliza cantidades, fechas, estados, provisiones en curso, avances y respaldos.

La fuente maestra de información es `BI - PROVISIONES.xlsx`.

## 2. Información disponible

- Solicitudes y entregas de provisiones.
- Fecha límite, cantidad, destino, foja y orden de servicio.
- Provisiones en curso y alertas de vencimiento.
- Comparación entre total contractual y total entregado.
- Acceso a la base técnica y al informe anual descargable.

## 3. Automatizaciones

- **Actualización del tablero:** Power Automate lee las tablas del Excel maestro y envía la información actualizada al repositorio.
- **Publicación web:** cada cambio en la rama principal activa GitHub Actions y vuelve a publicar GitHub Pages.
- **Informe semanal:** todos los lunes a las 10:00 se envía un correo con acceso al tablero y al informe del periodo.
- **Vigencia programada:** los correos semanales se mantienen hasta diciembre de 2030, salvo modificación posterior.
